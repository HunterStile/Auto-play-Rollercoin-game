# RollerCoin Auto-Play Bot 1.3.0

Flappy Rocket and Token Blaster are now available in the configuration GUI.
Live wins have been reported for both games.

Download **RollerCoin-bot.exe** below. Close the old app, replace its executable,
and reopen it. Keep `game_config.json` and `Routine_config.py` beside the
executable to preserve your settings. No Python installation is required.

## Changes

- **Flappy Rocket (MVP):** automatically locates the gray board, tracks the
  blue cockpit and recognizes red/green pipe gaps. Spacebar pulses account for
  vertical speed, rocket size, pipe rods and jump cooldown. It keeps altitude
  before the first pipe and follows each gap until the rocket clears it.
  The user reported a win without errors on September 19, 2026.
- **Token Blaster (beta):** tracks the ship, retains nearby targets, fires in
  their lane and predicts projectile/enemy collisions. Movement stays held
  between valid readings; predicted danger overrides targeting. Includes
  improved detection for animated exhaust, muted colors and nearby divers.
- **Diagnostics and controls:** both games support read-only screenshot
  inspection and explicit standalone `--play` mode. Q stops a standalone run;
  unverified stops save a local diagnostic screenshot and reason. Flappy Rocket
  also supports annotated detection images with `--output`.
- **Routine integration:** configure each game's icon and Start positions,
  enable it in Game Order and save. Existing reward collection and navigation
  remain in use. Messages distinguish unverified results from detected endings.
- Application and Windows executable metadata now show version 1.3.0.

## Validation and limits

All 86 offline regression tests passed, including 19 new Flappy Rocket tests.
Screenshot checks cover 70%, 100% and 120% scale and different screen positions;
mocked input checks cover gap selection, motion, cooldown, missing detections,
stopping and synthetic end panels. Both games have user-reported live wins.

Flappy Rocket remains an MVP and Token Blaster remains beta. Later levels,
unseen artwork and crowded/curved enemy trajectories need further validation.
Flappy Rocket's cyan-panel heuristic detects an ending, not whether it was a
win. Token Blaster's automatic result recognition remains unverified. Unknown
readings pause input and stop after three seconds; timeouts do not count as wins.
Gameplay time limits are 65 seconds for Flappy Rocket and 90 for Token Blaster.

`SHA256SUMS.txt` contains the executable's SHA-256 checksum.
