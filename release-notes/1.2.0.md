# RollerCoin Auto-Play Bot 1.2.0

Download **RollerCoin-bot.exe** below. Close the old app, replace its executable,
and reopen it. Keep `game_config.json` and `Routine_config.py` beside the executable
to preserve your settings. No Python installation is required.

## Changes

- **Coin Match, through the supplied final-level boards:** added Monero, the
  blue/gray coin and the bright-yellow symbol coin. All seven coin types are
  distinguished, including two-tone bodies and shaded rims at different scales.
  Stable-board checks and scored match-3 swaps remain in place. Removed the
  outdated “level 1 - experimental” label from the GUI.
- **Coin Flip at higher levels:** real 16- and 20-card screenshots now cover
  detection, empty slots and visual memory. Black-and-white faces no longer
  become unknown and stall the bot. Silver Litecoin is now remembered as a
  face instead of mistaken for an empty slot; mismatches are recorded and the
  bot continues exploring other cards.
- **2048 Coins rework:** preserves the established down/left/down/right/down
  sequence, but checks the reward button's lettering and surrounding dialog
  before sending another arrow. Cyan tiles and the progress bar alone no
  longer trigger completion. A result must persist across readings at least
  0.25 seconds apart. Added an offline inspection/manual-round script.
- **Real-time safety limits:** 2048 uses a 120-second ceiling, allowing longer
  high-level rounds, instead of counting 64 pattern repetitions. CoinClick and
  Hamster Climber now stop after 75 seconds, including during pixel scans, and
  stop scanning immediately when the end color is found. Timeouts return an
  unverified result. Normal end detection can stop each game sooner.
- Updated documentation, diagnostic output, screenshot fixtures, application
  title and Windows file/product version metadata for 1.2.0.

## Current play-loop limits

| Game | Maximum time |
| --- | ---: |
| 2048 Coins | 120 seconds |
| Coin Flip | 75 seconds |
| Coin Match | 75 seconds |
| CoinClick | 75 seconds |
| Hamster Climber | 75 seconds |
| Coin Fisher | 65 seconds |
| Flappy Rocket / Token Blaster (disabled in GUI) | 65 seconds |

These limits cover gameplay loops, not loading, reward collection or refresh
delays. The routine continues cycling through the configured games.

## Validation and limits

All 48 offline regression tests passed. Additional mocked checks verified
75-second timeout and normal-end behavior for CoinClick and Hamster Climber.

Screenshot regressions check recognition at 70%, 100% and 120% scale, board
coordinates, unknown/missing cells, legal moves and mocked input/memory flows.
2048 tests distinguish the supplied win dialog from gameplay, reject incomplete
or ambiguous panels and verify stable confirmation and the real-time deadline.
Live timing and unseen result layouts still require gameplay verification.
Flappy Rocket and Token Blaster remain disabled in the GUI.

`SHA256SUMS.txt` contains the executable's SHA-256 checksum.
