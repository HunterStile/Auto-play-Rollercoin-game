# RollerCoin Auto-Play Bot 1.1.0

Download **RollerCoin-bot.exe** below. No Python installation is required.
Close the old app, replace its executable, then reopen it. Keep your existing
`game_config.json` and `Routine_config.py` beside the executable to preserve settings.

## Changes

- **Coin Match level 1:** automatic grid and coin detection, stable-board checks,
  scored swaps and feedback when a move is not accepted. Selectable as experimental.
- **Coin Flip:** automatic card-grid detection, image-based memory and preference
  for known pairs. No manual difficulty selection is needed.
- Fixed Coin Flip stopping after a match because card highlights invalidated the grid.
- Coin Match and Coin Flip detect the shared cyan end panel, returning control
  to the routine for the configured **Claim reward** click.
- **Coin Fisher:** adaptive board detection and individual coin targeting.
- Windows file/product version metadata now identifies **1.1.0**.

## Validation and limits

- 33 offline regression tests, including the routine's reward-collection path.
- Coin Flip's 12-card layout is covered by real screenshots. 16/20-card layouts
  are tested with synthetic racks and still need real higher-level samples.
- End-panel recognition uses the common cyan color and has synthetic regression
  coverage; it does not distinguish a win from a loss.
- Coin Match remains experimental for level 1. Flappy Rocket and Token Blaster
  remain disabled.

`SHA256SUMS.txt` contains the SHA-256 checksum of the executable.
